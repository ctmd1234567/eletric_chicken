# Det-MSCEA 第二轮修复与验收

2026-11-04，审查基线 `14d01b53`。本轮保持检测任务适配定位，沿用既有优化器；正式实验仍受真实 Mask 与原始 B0–B8 定义缺失的限制。

## 修改前证据

1. `FrozenYOLOFeatureEvaluator.feature_for_bbox()` 对 bbox 对应特征矩形直接求均值。参考库和候选都调用它，未读取已经提供的实例 Mask，优化目标可能受框内背景主导。
2. `_new_background_confidence()` 只处理 class 0，并通过检测框中心判定 ROI 外。完全位于 ROI 内的新 fire 会被漏掉；中心在 ROI 内但跨边界的 smoke 框也不受约束。
3. `detection_constraint_violation()`、候选档案和逐次日志没有独立 fire 项，无法证明最终样本满足火焰误报约束。

## 本轮规则

- 同一条 Mask 特征路径用于参考与候选：二值实例 Mask 按实际 LetterBox 整数尺寸与 padding 映射到网络输入，再用面积插值投影到特征网格，按覆盖权重归一化池化。保留微小的分数权重；没有可用权重或出现非有限值则判无效，不回退到矩形均值。此特征仍有神经网络感受野带来的背景上下文，不能保证完全隔离烟雾。
- smoke C2 检查任何正面积越出 ROI 的新增框；仅接触边缘且无越出面积的框不算跨界。
- 新增独立 C5 fire 约束：检查全图新增 class 1，包括烟雾所在 ROI 内。fire 和 smoke 分别与同类 baseline 一对一匹配。仅达到对应告警阈值的原检测可豁免新检测，避免极低置信度 baseline 掩盖跨阈值误报。已有达到阈值的同类匹配检测保持豁免；其置信度进一步增长不属于本轮“新增检测”定义。
- fire 评价值必须显式提供；缺失、NaN 或越界时按不可行处理。最终档案要求五项约束违反度均为零。
